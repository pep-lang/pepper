# #225 Self-host the compiler: closed (refreshed 2026-10-17)

#225 closed on GitHub 2026-10-11 04:32 UTC. The 2026-10-06/08 handoff that was here (layers, per-layer overhead, next steps) described work that has since merged; its history is in the PRs below.

## What landed
- Layers became compilation units and units are keyed on the interface hashes of what they read: #771-#774 (10-08), #776-#780, #795 (per-file units checked and compiled in parallel workers), #802 (pipelined layers), #814 (layers renamed to compilation units), #820.
- pepc took over pep-build's command line (#781, #792, #809), shipped as `pep-build` (#784) and builds the release (#787, #797).
- The Rust compiler was removed (#803, 2026-10-10), its suites ported to Pepper tests (#798), the Pepper `pep-lsp` shipped everywhere and nothing depends on `tools/lsp` (#806), and `pep-lsp` checks unit by unit reusing pepc's checked records (#807, #815).
- Releases from the self-hosted compiler: v0.9.0 and v0.9.1 (2026-10-11), v0.9.2 (2026-10-13), v0.9.3 in progress. The v0.4.0 release planned on 10-08 was superseded by the 0.9.x series.

## #810 cold self-build and edit speed (closed 2026-10-17)
The follow-up ticket "pepc: cold self-build is slower than the Rust-era compiler's (400 s vs 362 s on 4 cores)" was worked as the #857-#895 series (LTO objects in parallel, `-O2` without LTO unless `--lto=full`, per-unit re-checks of function bodies, methods, structs and fields).

Windows Worker measurements (SDG-JBOSWELL, 32 logical CPUs, `-O2`, installed 0.9.1 `pep-build` as stage 0, 2026-10-15/16):
- Cold self-build at `47af04c6` (after #888): 149.4 s and 149.3 s (baseline bar 362 s on 4 cores; not the same CPU count).
- Edit builds, warm cache (3 rounds): body edit 4.6-4.8 s, method add 4.7-5.1 s, private struct add 5.8-5.9 s, `ElementName` field add 13.4-13.6 s; link about 320-350 ms. Cloud baselines (4 cores): 9.2 s, about 10 s, 11-12 s, 32-33 s.
- Windows link bugs found on the way and fixed: command line too long (#887, #888 response file, backslashes escaped in `47af04c6`), `--lto=full` comdat error on `__pep_location.*` (#897, #903).
