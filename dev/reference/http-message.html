The Pepper Programming Language

Requests and responses

HTTP messages: Headers, Request and Response, the values a Client sends and receives and a Server handler takes and returns.

Source: runtime/http/message.pep

Headers

struct Headers

HTTP header fields, by name. Names ignore ASCII case: they are stored lowercased, so Content-Type and content-type are the same field. A name may hold several values, kept in the order added. Different names have no defined order, as HTTP allows.

Example

var headers = http.Headers();
headers.add("Accept", "text/html");
headers["accept"] = "application/json";   # replaces it
assert(headers["ACCEPT"] == "application/json", "one value");

Request

struct Request

An HTTP request.

A Client sends one: build it with a method and an absolute URL, then add headers and a body. A Server handler receives one, with url set to the target from the request line (/path?query) and the body read in full.

Example

var request = http.Request("POST", "http://localhost:8080/items").set_text("name=pepper");
request.headers["Content-Type"] = "application/x-www-form-urlencoded";

Fields

method

var method: String

The method, such as GET or POST.

url

var url: String

For a client, the absolute URL (https://host/path?query); for a server handler, the request target (/path?query).

headers

var headers: Headers

The header fields. A client adds Host, Content-Length (or Transfer-Encoding) and Connection itself.

Constructor

Request()

Parameters

  • method — the method, such as GET
  • url — the absolute URL to send it to

Returns

set_reader

set_reader(source: io.Reader, length: long = -1): Request

Sets the body to the bytes source gives, read as the request is sent rather than held in memory: a large file, or the output of a compress.CompressReader. With a length the client sends Content-Length; without one it sends the body chunked (Transfer-Encoding: chunked), which every HTTP/1.1 server accepts.

The source is read once, so a client cannot send the request again (to follow a redirect, for instance).

Parameters

  • source — the stream the body is read from, to its end
  • length — the number of bytes source gives, or -1 when it is not known

Returns

  • this request

Example

var file = io.File.open(io.Path("upload.bin")).value();
var request = http.Request("PUT", "http://localhost:8080/files/upload.bin").set_reader(file);

uri

uri(): Result<Uri>

Parses url as a URI reference: an absolute URL for a request a client sends, or the target (/items?page=2) for one a server received.

Returns

  • the parsed URL, or an error when url is not a valid URI reference (see Uri.parse)

path

path(): String

Returns the path of url, with its percent-escapes: / when the path is empty.

Returns

  • the path, such as /items, or an empty string when url is not a valid URI reference

query

query(): String

Returns the query of url: the text after ?, with its percent-escapes (see Uri.decode).

Returns

  • the query without the ?, or an empty string for none or when url is not a valid URI reference

body

body(): u8[]

Returns the body's bytes, as they were sent or received: use it for a binary body. The array is the body itself, not a copy. It is empty when the body comes from set_reader.

Returns

  • the body; empty for none

text

text(): String

Returns the body as text, decoded as UTF-8. For a binary body, call body() instead: here each byte that is not valid UTF-8 becomes U+FFFD, the replacement character.

Returns

  • the body's bytes decoded as a String

Response

struct Response

An HTTP response.

Client.send returns one with the body read in full; Client.open returns one whose body is read as it arrives, through reader(). A Server handler returns one: build it with a status, then add headers and a body, in memory (set_text, set_body) or streamed (set_reader). The server adds Content-Length (or Transfer-Encoding: chunked) itself.

Example

handle(request: http.Request): http.Response {
    var response = http.Response(200).set_text("hello");
    response.headers["Content-Type"] = "text/plain";
    return response;
}

Fields

status

var status: int

The status code, such as 200 or 404.

reason

var reason: String

The reason phrase, such as OK; the server sends the standard one for the status when this is empty.

headers

var headers: Headers

The header fields.

url

var url: String

For a response a Client returns, the URL it came from: the request's, or after redirects the last one's. Empty otherwise.

set_reader

set_reader(source: io.Reader, length: long = -1): Response

Sets the body to the bytes source gives, which the server reads and sends as it goes rather than holding them in memory. With a length the server sends Content-Length; without one it sends the body chunked to an HTTP/1.1 client, and to an HTTP/1.0 client sends it unframed and closes the connection after it.

Parameters

  • source — the stream the body is read from, to its end
  • length — the number of bytes source gives, or -1 when it is not known

Returns

  • this response

Example

download(request: http.Request): http.Response {
    var file = io.File.open(io.Path("large.bin")).value();
    return http.Response(200).set_reader(file);
}

body

body(): u8[]

Returns the body's bytes, as they were sent or received: use it for a binary body. The array is the body itself, not a copy. It is empty for a response from Client.open, whose body is read through reader(), and for one whose body comes from set_reader.

Returns

  • the body; empty for none

reader

reader(): io.Reader

Returns the body as a stream. For a response from Client.open it is the connection's BodyReader, which reads the body as it arrives and ends where the body ends; read it once. For a response whose body comes from set_reader it is that source, and otherwise an io.ByteReader over body().

Returns

  • the stream of the body's bytes

Example

var response = http.Client().open(http.Request("GET", url)).value();
var file = io.File.create(io.Path("download.bin")).value();
for (var chunk in response.reader().chunks(65536)) {
    file.write_all(chunk.value());
}

text

text(): String

Returns the body as text, decoded as UTF-8. For a binary body, call body() instead: here each byte that is not valid UTF-8 becomes U+FFFD, the replacement character.

Returns

  • the body's bytes decoded as a String

is_success

is_success(): bool

Reports whether the status is 2xx.
