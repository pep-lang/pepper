The Pepper Programming Language

The reflect module (compile time)

reflect exists only inside a static block, which runs while compiling. It needs no import. Everything here is evaluated by the compiler: the values are compile-time numbers, bools, strings, lists, and the members, cases, functions and attributes below. The Reflection and attributes chapter explains how a block mixes them with the code it emits.

The compiler provides reflect itself; this file only declares it, with [__BuiltIn], for this reference and the editor.

Source: runtime/reflect.pep

reflect.name

reflect.name<T>(): String

The name of type T as it is written in source, with its type arguments ("Box<int>", "Array<String>").

Type parameters

  • T — the type to name

Returns

  • the type's name

reflect.properties

reflect.properties<T>(): List<Member>

The public fields and properties of struct T, in declaration order, as members.

Type parameters

  • T — a struct

Returns

  • one member per public field or property

reflect.fields

reflect.fields<T>(): List<Member>

Every field of struct T, private ones and a property's storage included, in declaration order, as members. It is meant for code a struct's author writes, such as a field-by-field ==, so it is available only in the file that declares T; anywhere else it is an error that points at properties.

Type parameters

  • T — a struct declared in this file

Returns

  • one member per field

reflect.cases

reflect.cases<E>(): List<Case>

The cases of enum E, in declaration order.

Type parameters

  • E — an enum

Returns

  • one case per enum case

reflect.functions_with

reflect.functions_with<A>(): List<Function>

Every free function in the program that carries attribute A.

Type parameters

  • A — an attribute struct

Returns

  • one function per function marked [A]

reflect.is_same

reflect.is_same<A, B>(): bool

Whether A and B are the same type, after aliases (int and i32 are). A member's Type can be either argument: reflect.is_same<field.Type, String>().

Type parameters

  • A — the first type
  • B — the second type

Returns

  • whether they are the same type

reflect.has_attribute

reflect.has_attribute<T, A>(): bool

Whether struct or enum T carries attribute A. A member, case or function has the same test as a method with one type argument (field.has_attribute<A>()).

Type parameters

  • T — the struct or enum
  • A — the attribute struct

Returns

  • whether T carries A

reflect.attribute

reflect.attribute<T, A>(): A

The value of attribute A on struct or enum T: each field of attribute struct A by name (reflect.attribute<T, Deprecated>().message). It is an error when T does not carry A. A member, case or function has the same as a method with one type argument (field.attribute<A>()).

Type parameters

  • T — the struct or enum
  • A — the attribute struct

Returns

  • the attribute's value

reflect.has_build_option

reflect.has_build_option(name: String): bool

Whether the build defines build option name (-D NAME or -D NAME=value).

Parameters

  • name — the option's name: a letter or _, then letters, digits and _

Returns

  • whether it is defined

reflect.build_option

reflect.build_option(name: String): String

The value of build option name, as a string (-D NAME alone is "1"). It is an error when the build does not define the option.

Parameters

  • name — the option's name

Returns

  • the option's value

reflect.build_option

reflect.build_option(name: String, default: String): String

The value of build option name, as a string, or default when the build does not define it.

Parameters

  • name — the option's name
  • default — the value when the build does not define it

Returns

  • the option's value, else default

reflect.print

reflect.print<T>(value: T)

Writes value as a note each time the compiler runs the call, on every compile, including one that succeeds; in an unrolled loop the note says which pass printed it. See Seeing what a block does.

Type parameters

  • T — the value's compile-time kind

Parameters

  • value — any compile-time value

reflect.error

reflect.error(message: String)

Stops the compile with an error at the call.

Parameters

  • message — the error's text; an interpolated string can show the values that matter

reflect.assert

reflect.assert(condition: bool, message: String)

Stops the compile with an error at condition when it is false.

Parameters

  • condition — a compile-time condition
  • message — the error's text
