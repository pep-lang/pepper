The Pepper Programming Language

The simd module

SIMD vectors: Vector<T, N> holds N numbers of type T and computes on all of them at once, in the CPU’s vector registers.

Bring it in with import simd. T is an integer or floating-point type (byte, char, short, ushort, int, uint, long, ulong, float, double) and N, the lane count, is a power of two from 1 to 64, written as a number: simd.Vector<byte, 16>. A vector is a value ([Value]): it is stored inline, copied like a number, and safe to share between threads.

The operations compile to the target’s vector instructions: SSE2 on x86-64 (AVX2 with -march=x86-64-v3), NEON on arm64, and simd128 on WebAssembly with -msimd128. A target without vector registers gets the same results from scalar code. Sixteen bytes (Vector<byte, 16>, Vector<int, 4>, Vector<double, 2>) is the width every target handles well; wider vectors use several registers where the target has no wider ones.

Lane-wise comparisons (less, equal, …) give a Mask<N>, which selects lanes (select), answers any and all, and packs into a bit mask with to_bits, whose trailing_zeros finds the first match.

Example

import simd;

main(): int {
    var a = simd.Vector<int, 4>(10);
    var b = a + simd.Vector<int, 4>(5);
    assert(b[0] == 15 && b.sum() == 60, "lane-wise add");
    var over = b.greater(12);
    assert(over.all() && over.to_bits() == 0xF, "a mask per lane");
    return 0;
}

Source: runtime/simd/module.pep

Lane

trait Lane

The number types a Vector holds: every integer and floating-point type. The runtime declares the conformances; another type cannot be a lane.

IntegerLane

trait IntegerLane

The integer lane types, whose vectors have checked division, the bitwise operators, shifts and rotates.

FloatLane

trait FloatLane

The floating-point lane types, whose vectors have floating-point division, square_root, floor and ceiling.

Vector

[Value] struct Vector<T: Lane, N>

N lanes of the number type T, computed on together.

Integer +, - and * wrap around on overflow in each lane, as vector instructions do, where scalar arithmetic panics. Integer / and % panic on a zero divisor lane; shifts panic on a count outside the lane’s width. Every other operation is defined for every input.

Type parameters

  • T — the lane type: an integer or floating-point type
  • N — the lane count: a power of two from 1 to 64
