The Pepper Programming Language

Compiler built-ins

The types and functions the compiler provides itself: raw pointers, weak references, atomics, checked arithmetic and the other __ intrinsics the runtime is built on. Every program can use them without an import, but most code should not: the runtime wraps each in a safe API (Atomic<T>, Weak<T>, math.checked_add, …).

The compiler provides these itself; this file only declares them, with [__BuiltIn], for this reference and the editor.

Source: runtime/builtins.pep

__ptr

struct __ptr<T>

A raw pointer to a T in memory the program manages itself, as C’s T*. It is how the runtime and C interop reach memory directly; nothing checks that it is valid.

p[i] reads or writes the ith element, p + n and p - n move by n elements (bytes for __ptr<void>), and == and != compare addresses. A pointer is true when it is not null (__null). as converts to and from __ptr<void>; unsafe_cast converts to any other pointer or to an integer. A string literal converts to __ptr<char>.

Type parameters

  • T — the type pointed at; void for untyped memory

__weak

struct __weak<T>

A weak reference to a struct object, like C++’s std::weak_ptr<T>: it keeps the object’s memory but not the object alive. Copies step the weak count; make one with __weak_from, read it with __weak_upgrade. Use Weak<T>, which wraps it.

Type parameters

  • T — the struct or trait type pointed at

__null

const __null: __ptr<void>

The null pointer or reference: a __ptr<T> that points nowhere, or an empty slot of a struct type.

sizeof

sizeof<T>(): ulong

The size of T in bytes, as C’s sizeof; a struct reference is the size of a pointer. Written sizeof<T> or sizeof<T>().

Type parameters

  • T — the type to measure

Returns

  • its size in bytes

Reinterprets value as a T: a pointer as another pointer or an integer, an integer as a pointer, or a number as another of the same width. It never applies to a reference-counted type. Prefer as, which checks the conversion.

__caller_location

__simd

A vector of N lanes of the number type T, as LLVM’s <N x T>: what simd.Vector<T, N> and simd.Mask<N> (with bool lanes) hold. The __simd_ functions below compute on it, each lane at once. It is a value, with no references inside.

Type parameters

  • T — the lane type: an integer, floating-point or bool type
  • N — the lane count, written as a number (__simd<byte, 16>)
