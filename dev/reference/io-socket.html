The Pepper Programming Language

Sockets

TCP and UDP sockets: TcpListener accepts connections, TcpStream is one connection, UdpSocket sends and receives datagrams.

Every call blocks the calling thread until it completes (in a task, it parks only the task), or until the socket’s read or write timeout expires. Addresses are SocketAddress values; resolve turns a host name into them.

Source: runtime/io/socket.pep

TcpListener

[NotCopyable("owns an operating-system socket and cannot be copied")] struct TcpListener

A TCP socket that listens for connections.

TcpListener.bind opens one on a local address; each accept() waits for the next connection and returns it as a TcpStream together with the peer’s address. Binding to port 0 lets the system choose a free port; local_address() tells which.

On POSIX the listener sets SO_REUSEADDR, so a server can restart while connections from its previous run linger in TIME_WAIT. An IPv6 listener keeps the system’s default for accepting IPv4 too (on Linux and macOS it does, on Windows it does not).

Closing: the destructor closes the socket when the last reference goes; close() closes it earlier and reports errors. Every operation on a closed listener fails with an error no IoError predicate identifies (EBADF on POSIX, ERROR_INVALID_HANDLE on Windows).

See also

  • TcpStream

Example

import io;

var listener = io.TcpListener.bind(io.SocketAddress.parse("127.0.0.1:0").value()).value();
print(listener.local_address().value().to_string());   # 127.0.0.1:<port>
while (true) {
    var (stream, peer) = listener.accept().value();
    stream.write_all("hello " + peer.to_string());
}

incoming

incoming(): Incoming

Returns an iterator that accepts connections one at a time, for a for loop over incoming streams.

Each step waits in accept() and yields the connected stream, or the error accept() returned; an error does not end the iteration, so a server can log it and keep going, or break. The iteration ends once the listener is closed. Use accept() instead when the peer’s address is needed.

Returns

  • a new Incoming positioned before the first connection

Example

import io;

var listener = io.TcpListener.bind(io.SocketAddress.parse("127.0.0.1:8080").value()).value();
for (var connection in listener.incoming()) {
    if (connection.is_err()) {
        print(connection.error().message);
        continue;
    }
    connection.value().write_all("hello");
}

Incoming

struct Incoming

The iterator TcpListener.incoming() returns: each connection the listener accepts, as an IoResult<TcpStream>.

next() waits for the next connection; an accept error is yielded as an item rather than ending the iteration. The iteration ends once the listener is closed. The iterator holds a reference to the listener, so the listener stays open while the iterator lives.

SharedTcpListener

[Shared] struct SharedTcpListener

A TCP listening socket that any thread can accept connections on: the thread-safe counterpart of TcpListener, for servers that accept on every worker of async.run at once (see async.spawn_on_each_worker). Each connection goes to one of the threads waiting in accept, and the stream it returns belongs to that thread.

A shared function may capture it. There is no close(), since another thread may be waiting on it: the socket closes when the last reference goes, which, for accept loops in tasks, is once async.run has cancelled them (accept then fails and the loop returns).

See also

  • TcpListener

Example

import async;
import io;

main(): int {
    async.run(() => {
        var listener = io.SharedTcpListener.bind(io.SocketAddress.parse("0.0.0.0:7000").value()).value();
        async.spawn_on_each_worker(() => {
            while (true) {
                var accepted = listener.accept();
                if (accepted.is_err()) {
                    return;
                }
                var (stream, peer) = accepted.value();
                stream.write_all("hello");
            }
        });
    });
    return 0;
}

TcpStream

[NotCopyable("owns an operating-system socket and cannot be copied")] struct TcpStream

A TCP connection: a reliable, ordered stream of bytes in both directions.

Get one from TcpStream.connect (to an address), TcpStream.connect_host (to a host name) or TcpListener.accept. read appends what has arrived to a byte array and returns 0 once the peer has closed its side; write sends bytes.

Each call is one system call and blocks until it can make progress: a read returns as soon as some bytes are there, not when max bytes are, and a write may send fewer bytes than given. read_exact and write_all loop until done. Sending never raises SIGPIPE; writing to a connection the peer has closed fails with is_connection_reset().

Closing: the destructor closes the socket when the last reference goes; close() closes it earlier and reports errors. Every operation on a closed stream fails with an error no IoError predicate identifies (EBADF on POSIX, ERROR_INVALID_HANDLE on Windows).

See also

  • TcpListener

Example

import io;

var stream = io.TcpStream.connect_host("example.com", 80).value();
stream.write_all("HEAD / HTTP/1.0\r\n\r\n");
var reply = Array<u8>();
while (stream.read(reply, 4096).value() > 0) {
}

connect_timeout

static connect_timeout(address: SocketAddress, milliseconds: ulong): IoResult<TcpStream>

Opens a connection to address like connect, but gives up with is_timed_out() when it is not established within milliseconds, instead of after the system’s own limit (often minutes).

Parameters

  • address — the address to connect to
  • milliseconds — the longest wait, at most 4294967295 (about 49 days); 0 waits as long as connect does

Returns

  • the connected stream, with no read or write timeout; an error with is_timed_out() when the time runs out, is_invalid_input() when milliseconds is too large, or an error as for connect

Example

var r = TcpStream.connect_timeout(SocketAddress.parse("192.0.2.1:80").value(), 2000);
if (r.is_err() && r.error().is_timed_out()) {
    print("no answer within 2 seconds");
}

connect_host

static connect_host(host: String, port: u16): IoResult<TcpStream>

Resolves host with resolve and connects to the first of its addresses that accepts, trying them in order.

Parameters

  • host — a host name or an IP address
  • port — the port to connect to

Returns

  • the connected stream; the error from resolve when the name has no address, or the error from the last address tried

Example

set_read_timeout

set_read_timeout(milliseconds: ulong): IoResult<void>

Limits how long a read waits: when no data arrives for milliseconds, the read fails with is_timed_out() and the stream stays open for another try. Each wait counts on its own, so a read_exact may take longer in all. 0, the default, waits as long as it takes. It works outside a task and in one, where the task’s async.timeout can end the wait sooner.

Parameters

  • milliseconds — the longest wait, at most 4294967295 (about 49 days); 0 for none

Returns

  • an Ok result; an error with is_invalid_input() when milliseconds is too large, or an error when the stream is closed

Example

stream.set_read_timeout(5000);   # give up after 5 seconds of silence

into_transfer

into_transfer(): SocketTransfer

Moves the connection out of this stream, into a token another thread can take it from with TcpStream.adopt. The stream is closed afterwards (is_open() is false), and a task waiting on it on this worker wakes with an error.

Inside async.run a socket belongs to the worker that uses it; this is how a task hands a connection to a task on another worker, such as one started with async.spawn.

Returns

  • the token; for a closed stream, one that adopt fails on

Example

import async;
import io;

serve(listener: io.TcpListener) {
    var (stream, peer) = listener.accept().value();
    var transfer = stream.into_transfer();
    async.spawn<void>(() => {
        var mine = io.TcpStream.adopt(transfer).value();
        mine.write_all("hello from another worker");
    });
}

SocketTransfer

[Shared] struct SocketTransfer

A connection on its way from one thread to another: made by TcpStream.into_transfer (or UnixStream.into_transfer), taken by TcpStream.adopt (or UnixStream.adopt, for a Unix domain connection). Unlike a stream, it is thread-safe, so a shared function (a body for async.spawn or Thread.spawn) can capture it and a Channel can carry it. If no one adopts it, the connection is closed when the last reference goes.

Parameters

UdpSocket

[NotCopyable("owns an operating-system socket and cannot be copied")] struct UdpSocket

A UDP socket: sends and receives datagrams, each delivered whole or not at all, in no guaranteed order.

UdpSocket.bind opens one on a local address (port 0 for any free port). send_to and receive_from name the peer on each call; after connect, send and receive use the connected peer and ignore datagrams from anyone else.

Each receive takes one datagram. A datagram longer than max is truncated to max bytes and the rest is lost, so size max for the largest datagram expected (at most 65507 bytes over IPv4).

Closing: the destructor closes the socket when the last reference goes; close() closes it earlier and reports errors.

Example

import io;

var socket = io.UdpSocket.bind(io.SocketAddress.parse("0.0.0.0:9000").value()).value();
var buffer = Array<u8>();
var (n, from) = socket.receive_from(buffer, 65507).value();
socket.send_to(buffer, from);   # echo it back
