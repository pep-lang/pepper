The Pepper Programming Language

Tasks

Tasks: functions that run concurrently on a few worker threads, each on its own small stack, switching only where they wait.

run(body) turns the calling thread into the first worker, starts the others, and runs body as the first task. A task starts others with Task<T>.spawn_local (on its own worker) or spawn (on any worker), and gives its worker to the other tasks there whenever it waits: sleep, yield_now, and Task.join, whenever a socket call would block, and whenever it waits on a Mutex, Condition or Channel. Nothing preempts a task, so a task that computes for a long time without waiting keeps every other task on its worker waiting too.

A task is a green thread (a fiber): an ordinary function with its own stack, so code that waits looks the same as code that does not, and a function called in a task can wait without being marked in any way.

Source: runtime/async/task.pep

Task

struct Task<T>

A task started with spawn_local or spawn, and the value its body returns.

Type parameters

  • T — the type of the body's result; void when there is none

Example

import async;

main(): int {
    async.run(() => {
        var a = async.Task<int>.spawn_local(() => { return 20; });
        var b = async.Task<int>.spawn_local(() => { return 22; });
        print(a.join().value() + b.join().value());   # 42
    });
    return 0;
}

run

run(body: () => void)

Runs body as the first task of a new runtime, and returns once body has returned and every task it started has finished. The calling thread is the first worker; the runtime starts one more thread per logical CPU after it (see RuntimeOptions.workers). When body returns, the tasks still running are cancelled (see Task.cancel), on every worker, and run waits for them to finish.

Parameters

  • body — the first task

Panics

  • if called inside a task, or if every remaining task is waiting on another and none can continue

Example

import async;

main(): int {
    async.run(() => {
        var t = async.Task<void>.spawn_local(() => {
            async.sleep(10);
            print("second");
        });
        print("first");
        t.join();
    });
    return 0;
}

spawn

spawn<T: Shared>(body: shared () => T): Task<T>

Starts a task that runs body on whichever worker is free first, and returns it. Unlike Task<T>.spawn_local, the task may run on another thread, in parallel with the calling task, so the body must be a shared function (it may capture only thread-safe values) and its result crosses threads, so T is constrained Shared: a thread-safe type such as a number, a [Shared] struct, or a shared function type (spawn<String> is a compile error at String).

A task, once started, stays on the worker that started it. Joining and cancelling work as for spawn_local.

Type parameters

  • T — the type of the body's result, which must be thread-safe (T: Shared); void when there is none

Parameters

  • body — the task's code

Returns

  • the task

Panics

  • outside run

Example

import async;

sum(from: long, to: long): long {
    var total: long = 0;
    var i = from;
    while (i < to) {
        total = total + i;
        i = i + 1;
    }
    return total;
}

main(): int {
    async.run(() => {
        var low = async.spawn<long>(() => { return sum(0, 500000); });
        var high = async.spawn<long>(() => { return sum(500000, 1000000); });
        print(low.join().value() + high.join().value());   # 499999500000
    });
    return 0;
}

spawn_on_each_worker

spawn_on_each_worker(body: shared () => void): Array<Task<void>>

Starts one task on every worker, each running body, and returns them in worker order. Use it to give each worker its own copy of a loop, such as a server's accept loop on an io.SharedTcpListener, so that every worker takes part. Each task runs on its own worker, the calling task's worker included; they are otherwise like tasks from spawn, and body must be a shared function.

Parameters

  • body — the code each worker runs

Returns

  • one task per worker, the first on the first worker

Panics

  • outside run

Example

import async;
import io;

main(): int {
    async.run(() => {
        var listener = io.SharedTcpListener.bind(io.SocketAddress.parse("0.0.0.0:7000").value()).value();
        var loops = async.spawn_on_each_worker(() => {
            while (true) {
                var accepted = listener.accept();
                if (accepted.is_err()) {
                    return;
                }
                var (stream, peer) = accepted.value();
                async.Task<void>.spawn_local(() => {
                    stream.write_all("hello");
                });
            }
        });
        for (var loop in loops) {
            loop.join();
        }
    });
    return 0;
}

run_blocking

run_blocking<T: Shared>(body: shared () => T): T

Runs body on a separate thread and returns what it returns, parking the calling task meanwhile so the worker keeps running other tasks. Use it for work that would otherwise hold the worker up: a call that blocks in the operating system (reading a file, resolving a host name, a C library that waits) or a long computation.

The runtime keeps a pool of threads for these calls, started as needed up to RuntimeOptions.blocking_threads. body runs on one of them, so it must be a shared function and T is constrained Shared, as for spawn. On a pool thread, sockets block the thread, and sleep and the other task functions behave as outside run.

body always runs to the end: cancelling the calling task, or a timeout around the call expiring, takes effect once run_blocking has returned. Outside a task, run_blocking just calls body.

Type parameters

  • T — the type of the body's result, which must be thread-safe (T: Shared); void when there is none

Parameters

  • body — the blocking code

Returns

  • what body returns

Example

import async;

main(): int {
    async.run(() => {
        var ticker = async.Task<void>.spawn_local(() => {
            async.sleep(10);
            print("the worker kept running");
        });
        var answer = async.run_blocking<int>(() => {
            async.Thread.sleep(50);   # blocks a pool thread, not the worker
            return 42;
        });
        print(answer);
        ticker.join();
    });
    return 0;
}

Deadline

struct Deadline

A time limit on the waits inside a with block, made by timeout.

While the block runs, a socket call that has to wait fails with an IoError for which is_timed_out() holds once the limit passes, Task.join fails with a TaskError for which is_timed_out() holds, and sleep returns early. Code that does not wait is never interrupted. Timeouts nest: an inner one cannot extend an outer one.

Constructor

Deadline()

Parameters

  • milliseconds — how long from now the limit passes

Methods

Returns

  • this deadline

Panics

  • outside a task

exit

exit()

Stops applying the limit; the end of the with block calls it.

is_expired

is_expired(): bool

Returns whether the limit has passed.

Returns

  • true once the time is up

timeout

timeout(milliseconds: ulong): Deadline

Returns a time limit for a with block: the waits inside it give up milliseconds from now (see Deadline).

Parameters

  • milliseconds — how long the block's waits may take in all

Returns

  • the limit, for a with header

Example

import async;
import io;

main(): int {
    async.run(() => {
        var listener = io.TcpListener.bind(io.SocketAddress.parse("127.0.0.1:0").value()).value();
        with (var deadline = async.timeout(50)) {
            var accepted = listener.accept();   # nobody connects
            assert(accepted.error().is_timed_out(), "timed out");
        }
    });
    return 0;
}
