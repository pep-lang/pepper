The Pepper Programming Language

TomlValue

TomlValue: a TOML value of any kind, and TomlDateTime, TOML's dates and times.

Source: runtime/toml/value.pep

TomlDateTime

struct TomlDateTime

A TOML date, time, or date and time: an offset date-time (1979-05-27T07:32:00Z), a local date-time (1979-05-27T07:32:00), a local date (1979-05-27) or a local time (07:32:00.5).

has_date, has_time and has_offset say which of the four it is; the fields of a part it does not have are 0. to_string() writes it in the RFC 3339 form TOML uses, with as many fraction digits as it was read with.

Example

import toml;

var when = toml.TomlDateTime.offset(1979, 5, 27, 7, 32, 0, -420);
assert(when.to_string() == "1979-05-27T07:32:00-07:00", "an offset");
assert(toml.TomlDateTime.date(2024, 2, 29).to_string() == "2024-02-29", "a date");

TomlValue

enum TomlValue

A TOML value: a string, an integer, a float, a boolean, a date-time, an array or a table. toml.parse makes a table from a document, and to_document writes one back.

Look members up with value["key"] and elements with value[index], which panic when there is none; try_get and lookup give none instead, and lookup follows a dotted key ("package.name"). Then read the value with an as_ method, which gives none when the value is of another kind, or match on its case.

A Table keeps its keys in the order they were written. An Array or Table case holds its array or map by reference, so changing them through value[key] = ... or append changes every holder of the value.

Example

import toml;

var package = toml.TomlValue.table();
package["name"] = toml.TomlValue.String("demo");
package["authors"] = toml.TomlValue.array([toml.TomlValue.String("Ada")]);
assert(package.to_string() == "{ name = \"demo\", authors = [\"Ada\"] }", "inline");
assert(package["name"].as_string().value() == "demo", "a lookup");

lookup(key: String): TomlValue?

Returns the value at a dotted key below this table, read as TOML reads a key: package.name, dependencies."my.crate".version.

Parameters

  • key — the dotted key

Returns

  • the value, or none when a part is missing, is not a table, or key is not a valid TOML key

Example

import toml;

var root = toml.parse("[package]\nname = \"demo\"").value();
assert(root.lookup("package.name").value().as_string().value() == "demo", "found");
assert(root.lookup("package.version").is_empty(), "missing");

to_document

to_document(): String

Returns a table as a TOML document: its plain members as key = value lines, then each table member under a [header] and each array of tables as [[header]] sections, nested tables after their parent's members.

Returns

  • the document text, ending with a line break unless it is empty

Panics

  • if this is not a table ("TomlValue.to_document needs a table")

Example

import toml;

var root = toml.TomlValue.table();
root["title"] = toml.TomlValue.String("demo");
var server = toml.TomlValue.table();
server["port"] = toml.TomlValue.Integer(8080);
root["server"] = server;
assert(root.to_document() == "title = \"demo\"\n\n[server]\nport = 8080\n", "a document");
