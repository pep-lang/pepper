The Pepper Programming Language

Server

The HTTP server: Server accepts HTTP/1.1 and HTTP/2 connections on every worker of async.run and answers each request with a handler function.

Source: runtime/http/server.pep

MAX_REQUEST_BODY

const MAX_REQUEST_BODY: ulong = 16777216

The largest request body a Server reads: 16 MiB. A larger one gets 413 Content Too Large.

Server

[Shared] struct Server

An HTTP/1.1 and HTTP/2 server.

Server.bind listens on an address (Server.bind_tls serves HTTPS); serve then accepts connections on every worker of the running async.run and serves each connection in a task of its own, calling the handler for every request. Connections are kept open between requests unless the client asks to close (or speaks HTTP/1.0).

The handler gets the Request with its body read in full and returns the Response; the server adds Content-Length (and Connection: close when it will close). A request the server cannot parse gets 400 Bad Request, one with header fields over 64 KiB 431 Request Header Fields Too Large, and one with a body over MAX_REQUEST_BODY 413 Content Too Large; the connection then closes.

HTTP/2 is served to a client that chooses it through ALPN (see bind_tls) or that starts a plain TCP connection with the HTTP/2 preface (prior knowledge): each stream is a request, answered by the same handler in a task of its own.

Example

import async;
import http;
import io;

hello(request: http.Request): http.Response {
    var response = http.Response(200).set_text("hello from " + request.path());
    response.headers["Content-Type"] = "text/plain";
    return response;
}

main(): int {
    async.run(() => {
        var server = http.Server.bind(io.SocketAddress.parse("0.0.0.0:8080").value()).value();
        server.serve(hello);
    });
    return 0;
}

serve

serve(handler: shared (Request) => Response)

Serves connections until the task is cancelled (when async.run ends): accepts on every worker and serves each connection in a task on the worker that accepted it.

Parameters

  • handler — answers one request; it runs in the connection's task, so it may wait (on sockets, files, locks) without holding up other connections

Panics

  • outside async.run

Connection

struct Connection

A connection a Server handler took over by answering with Response.upgrade: the raw stream after the 101 Switching Protocols head, TCP or (under Server.bind_tls) TLS, as an io.Reader and an io.Writer.

Reads return first the bytes the server had already read past the request (a client may send its first message right after the request), then what arrives. Like the handler, it belongs to the connection's task.

Example

upgraded(request: http.Request): http.Response {
    return http.Response().upgrade("echo", (connection) => {
        var data = Array<u8>();
        while (connection.read(data, 4096).value() > 0) {
            connection.write_all(data);
            data.clear();
        }
    });
}
