The Pepper Programming Language

Time

Clocks and spans of time: Duration, Instant for measuring, and SystemTime for the wall clock.

Source: runtime/os/time.pep

Duration

[Value] struct Duration

A span of time, counted in nanoseconds, like Rust's std::time::Duration. It is never negative and reaches about 584 years.

Make one with from_seconds, from_milliseconds, from_microseconds or from_nanoseconds, or by subtracting two Instants. A value struct: it is copied, compared with ==, and allocates nothing.

Example

import os;

main(): int {
    var timeout = os.Duration.from_seconds(2) + os.Duration.from_milliseconds(500);
    print(timeout.milliseconds());   # 2500
    print(timeout);                  # 2.5s
    return 0;
}

Instant

[Value] struct Instant

A moment on a monotonic clock, for measuring how long something takes, like Rust's std::time::Instant.

The clock only moves forward: setting the system's date and time does not change it. Its readings mean nothing by themselves, only the Duration between two of them, and they cannot be compared across processes or reboots. Use SystemTime for the date and time.

The clock is CLOCK_MONOTONIC on Linux and macOS and QueryPerformanceCounter on Windows, read to the nanosecond.

Example

import os;

main(): int {
    var start = os.Instant.now();
    ulong total = 0;
    for (var i in 0..1000000) {
        total += i as ulong;
    }
    var elapsed = os.Instant.now() - start;
    print($"summed in {elapsed.milliseconds()} ms");
    return 0;
}

SystemTime

[Value] struct SystemTime

A date and time on the system's wall clock, counted in nanoseconds from the Unix epoch (1970-01-01 00:00:00 UTC), like Rust's std::time::SystemTime. It reaches from the year 1677 to 2262.

The wall clock can jump, backwards too, when the system's time is set, so measure how long something takes with Instant instead. The time module turns it into dates, times of day and time zones, and back.

Example

import os;

main(): int {
    var now = os.SystemTime.now();
    print($"{now.unix_seconds()} seconds since 1970");
    return 0;
}
