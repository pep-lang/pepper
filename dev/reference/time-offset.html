The Pepper Programming Language

Offsets

Fixed offsets from UTC, Offset, and the date and time at one, OffsetDateTime: an instant written the way RFC 3339 and TOML write it.

Source: runtime/time/offset.pep

Offset

[Value] struct Offset

A fixed offset from UTC, east positive: +02:00 for Central European Summer Time, -05:00 for US Eastern Standard Time, +00:00 for UTC.

A value struct: copied, compared with ==, and never allocated. It is less than a day either way, to the second. Its text is +02:00, with the seconds when there are any (+00:19:32).

Example

import time;

main(): int {
    var india = time.Offset.from_hours(5, 30);
    print(india);            # +05:30
    print(india.seconds);    # 19800
    return 0;
}

OffsetDateTime

[Value] struct OffsetDateTime

A date and time at a fixed offset from UTC, such as 2024-03-01T09:00:00+01:00: an instant, together with the local date and time it was written in. This is RFC 3339's timestamp and TOML's offset date-time.

A value struct: copied and never allocated. == compares the date, time and offset, so the same instant at two offsets is not ==; compare instants with to_system_time(), or with < and the other comparisons, which compare instants. Its text is RFC 3339's, with Z for UTC.

Example

import time;

main(): int {
    var meeting = time.OffsetDateTime.parse("2024-03-01T09:00:00+01:00").value();
    print(meeting.to_utc());   # 2024-03-01T08:00:00Z
    print(meeting.to_http_date());   # Fri, 01 Mar 2024 08:00:00 GMT
    return 0;
}

parse_http_date

static parse_http_date(text: String): Result<OffsetDateTime>

Returns the HTTP date in text, as RFC 9110 defines it, or an error when it is not one. It reads the preferred IMF-fixdate (Sun, 06 Nov 1994 08:49:37 GMT) and the two obsolete forms that servers must still accept: RFC 850's (Sunday, 06-Nov-94 08:49:37 GMT, where a two-digit year from 70 is in the 1900s and below 70 in the 2000s) and C's asctime (Sun Nov 6 08:49:37 1994). The weekday must match the date.

Parameters

  • text — the text to read

Returns

  • the date and time in UTC, or an error saying what is wrong with text

format

format(pattern: String): String

Returns the date and time as text laid out by pattern, whose % codes are those of C's strftime (see the time module). %z is the offset as +0200, %:z as +02:00, and %s the Unix seconds.

Parameters

Returns
