The Pepper Programming Language

Numbers

Reading numbers from text, and arithmetic that says what to do on overflow.

Every number type has a static parse: int.parse("42") gives an int?, empty when the text is not a number of that type. The integer types take a base from 2 to 36; float and double read decimal notation. Each spelling of a type is the same type, so i32.parse is int.parse.

Integer +, - and * panic on overflow. Each integer type also has wrapping_add (the result modulo 2^bits), checked_add (none on overflow), saturating_add (clamped to the type’s range) and overflowing_add (the wrapped result and whether it overflowed), with sub and mul forms of each.

Each integer type also has bit operations that compile to one instruction on most CPUs (leading_zeros, trailing_zeros, count_ones, count_zeros, swap_bytes, reverse_bits, rotate_left, rotate_right), and min, max and, when signed, abs. float and double have square_root, floor, ceiling, truncate, round, abs, copy_sign, multiply_add, min and max.

Example

var port = int.parse("8080");
assert(port.is_value() && port.value() == 8080, "parsed");
assert(byte.parse("256").is_empty(), "too big for a byte");
int big = 2147483647;
assert(big.wrapping_add(1) == -2147483648, "wraps around");
assert(big.checked_add(1).is_empty(), "does not fit");
assert((40 as uint).trailing_zeros() == 3, "40 is 0b101000");

Static methods

parse

static parse(text: String, base: int = 10): char?

Parses text as a char (i8) written in base: an optional + or -, then one or more digits, and nothing else. Digits past 9 are the letters, either case. No spaces, prefixes (0x) or separators are accepted.

Parameters

  • text — the text to parse
  • base — the base the digits are written in, from 2 to 36; 10 by default

Returns

  • the value, or none when text is not an integer in base or the value is outside -128 to 127

Panics

  • if base is less than 2 or greater than 36

Example

assert(i8.parse("-128").value() == -128, "the lowest");

is_digit

is_digit(): bool

Whether this is an ASCII decimal digit, 0 to 9, like C’s isdigit.

Like every classification method on char, it looks at ASCII only, as C does in the “C” locale: a negative char (a byte of UTF-8 text above 127) is never a digit, letter, space or punctuation. Unlike C’s functions, it is defined for every value, negative ones included.

Returns

  • true for 0 to 9

rotate_left

rotate_left(count: int): char

Returns this value’s bits rotated left by count: the bits shifted out at the top come back in at the bottom (llvm.fshl). count is taken modulo 8, so a negative count rotates right.

Parameters

  • count — how many places to rotate

Returns

  • the rotated value

Example

abs

abs(): char

Returns the absolute value: this without its sign. The lowest value, -128, has no positive counterpart in a char, so it panics, as its negation does.

Returns

  • -this when this value is negative, else this

Panics

  • if this value is -128 (“integer overflow in ‘char’ absolute value”)

Example

assert((-5 as char).abs() == 5, "negative");
