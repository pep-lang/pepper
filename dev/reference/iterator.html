The Pepper Programming Language

Iterators

Source: runtime/iterator.pep

Iterator

trait Iterator<T>

Something a for loop can step through, one element at a time.

for (var x in source) drives a source that declares next() and current() directly: it calls next() before each pass and binds current() to the loop variable while next() returns true. A type whose for loop should go through a separate iterator implements Iterable<T> instead. A type with neither protocol is a compile error in a for loop.

The loop goes by the methods a type has, so declaring the trait is optional. Declaring it (extend Foo with Iterator<int>;) checks that the methods match and lets the type be used as an Iterator<int> value, which a for loop drives through the trait.

Type parameters

  • T — the type of the elements produced

See also

  • Iterable

Example

struct Countdown {
    int remaining;
    int now;

    construct(this.remaining = 0) {}

    bool next() {
        if (remaining == 0) {
            return false;
        }
        now = remaining;
        remaining = remaining - 1;
        return true;
    }

    int current() {
        return now;
    }
}

extend Countdown with Iterator<int>;

main(): int {
    var total = 0;
    for (int n in Countdown(3)) {
        total = total + n;   # visits 3, 2, 1
    }
    assert(total == 6, "3 + 2 + 1");
    return 0;
}

Methods

next

next(): bool

Advances to the next element.

The first call moves to the first element, if any. Once it returns false it must keep returning false.

Returns

  • true if there is a current element, false when the elements are exhausted

current

current(): T

Returns the element the last successful next() moved to.

Calling it before the first next(), or after next() returned false, is an error; the runtime's iterators panic in that case.

Returns

  • the current element

map

map<U>(transform: (T) => U): MapIterator<T, U>

Returns an iterator over transform applied to each element, in order.

Lazy: transform runs once per element, as the result is advanced, and the result advances this iterator. Every type that declares Iterator<T> gets this method.

Type parameters

  • U — the type transform returns

Parameters

  • transform — the function applied to each element

Returns

  • a MapIterator<T, U> over the transformed elements

Example

var names = Array<String>();
for (var size in names.iterate().map((name) => name.size)) {
    print(size);
}

filter

filter(keep: (T) => bool): FilterIterator<T>

Returns an iterator over the elements for which keep returns true, in order.

Lazy: keep runs once per element, as the result is advanced, and the result advances this iterator. Every type that declares Iterator<T> gets this method.

Parameters

  • keep — the test an element must pass

Returns

  • a FilterIterator<T> over the elements that pass

Example

var nums = Array<int>();
for (var even in nums.iterate().filter((n) => n % 2 == 0)) {
    print(even);
}

enumerate

enumerate<TIndex=ulong>(): EnumerateIterator<T, TIndex>

Returns an iterator over the elements paired with their positions: (0, first), (1, second), and so on.

Lazy, like map. Destructure the pair in the loop to name both parts. The positions count in ulong, like Array.count; name another integer type to count in it (enumerate<int>()). Every type that declares Iterator<T> gets this method.

Type parameters

  • TIndex — the integer type of the positions, ulong by default

Returns

  • an EnumerateIterator<T, TIndex> over (index, element) tuples

Example

var names = ["Ada", "Grace"];
for (var (i, name) in names.iterate().enumerate()) {
    print($"{i}: {name}");   # 0: Ada, then 1: Grace
}

zip

zip<U>(other: Iterator<U>): ZipIterator<T, U>

Returns an iterator over pairs of this iterator's elements and other's, in step: (first, other's first), and so on. It stops when either runs out.

Lazy, like map. Every type that declares Iterator<T> gets this method.

Type parameters

  • U — the type of other's elements

Parameters

  • other — the iterator whose elements form the second half of each pair

Returns

  • a ZipIterator<T, U> over (element, other element) tuples

Example

var names = ["Ada", "Grace"];
var ages = [36, 45];
for (var (name, age) in names.iterate().zip(ages.iterate())) {
    print($"{name} is {age}");
}

take

take<TElement=T>(count: ulong): TakeIterator<TElement>

Returns an iterator over at most the first count elements.

Lazy, like map: it stops after count elements, or sooner when this iterator runs out, and never advances this iterator past them. Every type that declares Iterator<T> gets this method.

flat_map<U>(transform: (T) => Iterator<U>): FlatMapIterator<T, U>

Lazy, like map: transform runs on a source element only once the iterator from the one before it has run out. Every type that declares Iterator<T> gets this method.

Type parameters

Example

to_array

to_array(): Array<T>

Returns a new Array holding the remaining elements, in order.

Runs the iteration to the end. Like the adapters, it works on a copy of the iterator, so a value iterator (every runtime iterator is one) is left where it was. Every type that declares Iterator<T> gets this method.

Returns

  • the elements, possibly none

Example

var evens = (1..>10).filter((n) => n % 2 == 0).to_array();   # [2, 4, 6, 8, 10]

sum

sum<TSum=T>(): TSum

Returns the sum of the elements, with +.

For element types that have +, such as the numbers. The sum is kept in TSum, the element type unless named: sum<long>() adds int elements without overflowing an int. Runs the iteration to the end, on a copy of the iterator, like to_array. Every type that declares Iterator<T> gets this method.

Type parameters

  • TSum — the type the sum is kept in, T by default

Returns

  • the sum, or TSum's default value (0 for a number) when there are no elements

Example

var total = (1..>4).sum();   # 10
var big = [2000000000, 2000000000].iterate().sum<long>();   # 4000000000

Iterable

trait Iterable<T>

Something that hands out an Iterator<T> over its elements, such as Array<T> and String (which yields one code point at a time, as a String).

for (var x in source) calls source.iterate() once, then drives the returned iterator with next() and current(). When a type declares both iterate() and next()/current(), the loop uses iterate().

Type parameters

  • T — the type of the elements produced

See also

  • Iterator

Example

var nums = Array<int>();
nums.append(1);
nums.append(2);
var total = 0;
for (var x in nums) {
    total = total + x;
}

Methods

iterate

iterate(): Iterator<T>

Returns a new iterator positioned before the first element.

The result may be any type that satisfies Iterator<T> (for example ArrayIterator<T>); each call starts a fresh, independent pass.

Returns

  • an iterator over the elements
