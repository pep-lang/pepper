The Pepper Programming Language

Machine

The machine the program runs on: its operating system, processor, memory and name.

Source: runtime/os/machine.pep

OperatingSystem

enum OperatingSystem

An operating system Pepper runs on, with the names [Target(OS(...))] uses.

See also

  • system_os

system_os

system_os(): OperatingSystem

Returns the operating system the program was built for.

Returns

  • the operating system

Example

import os;

main(): int {
    var executable = os.system_os() == os.OperatingSystem.Windows ? "tool.exe" : "tool";
    print(executable);
    return 0;
}

system_name

system_name(): String

Returns the name of the operating system the program was built for, in lowercase: "linux", "macos", "windows", "wasi", "ios" or "android", for printing and for file and directory names.

Returns

  • the operating system's name

See also

  • system_os

system_version

system_version(): String

Returns the operating system's version: the kernel release on Linux (uname -r, such as 6.8.0-45-generic), the product version on macOS (sw_vers -productVersion, such as 14.5), and the major, minor and build numbers on Windows (such as 10.0.22631). WASI does not report one.

Returns

  • the version, or an empty String when the system does not report it

architecture

hostname

hostname(): String

Returns the machine's host name, as hostname prints it (on Windows its DNS host name). WASI does not report one.

Returns

  • the host name, or an empty String when the system does not report it

logical_cpus

logical_cpus(): ulong

Returns the number of logical processors: every hardware thread, so a core with hyperthreading counts two or more times. On Linux a cgroup CPU quota (docker run --cpus) caps it, rounded up. The same as async.logical_cpus().

Returns

  • the number of logical processors, at least 1

See also

  • physical_cpus

physical_cpus

physical_cpus(): ulong

Returns the number of physical processor cores: hardware threads that share a core count once. The same as async.physical_cpus().

Returns

  • the number of physical cores, at least 1 and at most logical_cpus()

See also

  • logical_cpus

total_memory

total_memory(): ulong

Returns the machine's physical memory in bytes. Inside a virtual machine this is what the guest sees. On Linux, a lower memory limit on the process's cgroup or any cgroup above it (cgroup v2's memory.max or v1's memory.limit_in_bytes, as docker run --memory sets) is returned instead, as the JVM does. WASI does not report it.

Returns

  • the total physical memory, or the container's memory limit when that is lower, in bytes; 0 when the system does not report it

page_size

page_size(): ulong

Returns the size of a page of virtual memory in bytes: the unit the operating system maps memory in, usually 4096 (16384 on Apple silicon; 65536, WebAssembly's page, on WASI).

Returns

  • the page size in bytes
