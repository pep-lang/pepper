The Pepper Programming Language

Dates and times

Calendar dates and times of day with no time zone: Date, Time, DateTime and Weekday, on the proleptic Gregorian calendar, plus is_leap_year and days_in_month.

Source: runtime/time/civil.pep

is_leap_year

is_leap_year(year: int): bool

Returns whether year is a leap year on the Gregorian calendar: divisible by 4, except centuries not divisible by 400. Year 0 (1 BC) is one.

Parameters

  • year — the year

Returns

  • true when February of year has 29 days

Example

assert(time.is_leap_year(2024) && !time.is_leap_year(1900), "leap years");

Date

[Value] struct Date

A date on the proleptic Gregorian calendar, which extends the calendar's rules to years before it was adopted: a year, a month (1 to 12) and a day of the month (1 to 31), with no time of day or time zone.

A value struct: copied, compared with ==, < and the other comparisons, and never allocated. Years run from -999999 to 999999; year 0 is 1 BC. Its text is ISO 8601's 2024-02-29.

Example

import time;

main(): int {
    var day = time.Date(2024, 2, 28).add_days(1);
    print(day);               # 2024-02-29
    print(day.weekday());     # Thursday
    return 0;
}

Time

[Value] struct Time

A time of day with no date or time zone: an hour (0 to 23), a minute, a second and a nanosecond. Leap seconds are not represented, as in Unix time.

A value struct: copied, compared with ==, < and the other comparisons, and never allocated. Its text is ISO 8601's 08:30:00, with a fraction of a second when there is one (08:30:00.25).

Example

import time;

main(): int {
    var lunch = time.Time(12, 30);
    print(lunch);   # 12:30:00
    return 0;
}

DateTime

[Value] struct DateTime

A date and a time of day with no time zone, such as a meeting's 2024-03-01 09:00 written down without saying where. TOML calls it a local date-time. Attach an offset with OffsetDateTime, or a zone's rules with TimeZone.at_local, to name an instant.

A value struct: copied, compared with ==, < and the other comparisons, and never allocated. Its text is ISO 8601's 2024-03-01T09:00:00.

Example

import time;

main(): int {
    var start = time.DateTime(2024, 3, 1, 9, 0);
    var end = start + os.Duration.from_seconds(90 * 60);
    print(end);   # 2024-03-01T10:30:00
    return 0;
}
