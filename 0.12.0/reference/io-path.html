The Pepper Programming Language

Path

Source: runtime/io/path.pep

Path

struct Path

An owned file-system path: the text of the path plus operations on it (Rust's Path and PathBuf in one type).

Every method except exists, is_file, is_dir, metadata, symlink_metadata and canonicalize is pure text manipulation: it never touches the file system, so .. is not resolved against symlinks and nothing needs to exist. A part that may be missing comes back as an optional, as in Rust: parent() of a root is none.

Breaking change: parent(), file_name(), file_stem(), extension() and dot_index() used to return an empty Path or String (or name.size) for "none"; they now return Path?, String? and ulong?.

Separators: on POSIX only / separates components (\ is an ordinary byte of a name). On Windows both / and \ separate, and a path may start with a prefix: a drive (C:) or a UNC share (\\server\share). Methods that build a path (join, normalize, with_extension) insert the platform separator (separator()), but the rest of the text is kept as written. Paths are UTF-8 Strings, scanned byte by byte; separators and dots are ASCII, so splitting at them never cuts a character in two.

Example

import io;

var p = io.Path("docs").join("guide.md");   # "docs/guide.md"
var name = p.file_name().value();               # "guide.md"
var ext = p.extension().value_or("");           # "md"
var dir = p.parent();                           # some io.Path("docs")
if (p.is_file()) {
    print(p.to_string());
}

Properties

is_empty

var is_empty: bool { get; }

Whether the path has no text at all. File-system operations on the empty path fail.

Constructor

Path()

[Implicit] construct(value: String = "")

Creates a path holding value as is: no validation, normalization or separator conversion.

The constructor is [Implicit]: a String (or a string literal) converts to a Path wherever a Path is expected, so every API that takes a Path also accepts text.

Parameters

  • value — the path's text; the default, "", is the empty path

Example

import io;

var p = io.Path("/usr/lib");
var empty = io.Path();   # is_empty is true
var q: io.Path = "docs";   # converted implicitly

Static methods

separator

static separator(): String

Returns the separator this platform inserts when it builds a path.

Returns

  • "/" on POSIX, "\" on Windows (where / is also accepted as a separator on input)

dot_index

static dot_index(name: String): ulong?

Returns the byte offset of the dot that starts the extension in the file name name: the last . that is not the first byte. A leading dot (.bashrc) starts the name, not an extension.

Breaking change: this used to return name.size for "no extension"; it now returns none.

Parameters

  • name — a file name (one component, as file_name() returns)

Returns

  • the index of the extension's dot, or none when the name has no such dot (noext, .bashrc, the empty name)

Methods

to_string

to_string(): String

Returns the path's text, the same String the Path holds, not a copy.

Returns

  • the path as a String

is_absolute

is_absolute(): bool

Returns whether the path is absolute, meaning it does not depend on the current directory. Pure text: the path need not exist.

On POSIX a path is absolute when it starts with /. On Windows it is absolute when it has a drive followed by a root separator (C:\x, C:/x) or is a UNC path (\\server\share\x); a root without a drive (\x) and a drive without a root (C:x) are both relative. The empty path is relative.

Returns

  • true when the path is absolute

is_relative

is_relative(): bool

Returns whether the path is relative: the opposite of is_absolute(). The empty path is relative.

Returns

  • true when the path is not absolute

join

join(other: Path): Path

Returns this path with other appended as further components.

A platform separator is inserted between the two unless this path already ends in one. If other is absolute, or (on Windows) starts with a root separator or a drive or UNC prefix, it replaces this path instead, as in Rust. Joining an empty other returns a copy of this path; joining onto the empty path returns other. Nothing is normalized: a joined with ../b is a/../b.

Parameters

  • other — the path to append

Returns

  • a new Path; this path is not changed

Example

import io;

var p = io.Path("usr").join(io.Path("lib"));   # "usr/lib" ("usr\lib" on Windows)
var q = io.Path("a/").join(io.Path("b"));      # "a/b"
var r = io.Path("a").join(io.Path("/abs"));    # "/abs"
var so = io.Path("usr").join("lib").join("x.so");   # a String converts to a Path

join_str

[Deprecated("use 'join', which accepts a String", "join")] join_str(other: String): Path

Returns this path with the String other appended, exactly like join(Path(other)). Deprecated: join accepts a String directly, since a String converts to a Path implicitly.

Parameters

  • other — the path text to append

Returns

  • a new Path; this path is not changed

See also

  • join

Example

import io;

var so = io.Path("usr").join("lib").join("x.so");   # "usr/lib/x.so"

has_root_or_prefix

has_root_or_prefix(): bool

Returns whether the path starts with a root separator or, on Windows, a drive or UNC prefix. This is what makes join replace instead of append; unlike is_absolute() it is also true for Windows paths such as \x and C:x. On POSIX it equals is_absolute().

Returns

  • true when the path has a root separator or a prefix

parent

parent(): Path?

Returns the path without its last component. Pure text: .. is not resolved, so the parent of a/.. is a.

Trailing and repeated separators before the last component are dropped (a/b/ and a//b both give a). The parent of a top-level name keeps the root and prefix (/a gives /, C:\x gives C:\, C:x gives C:).

Breaking change: this used to return the empty path for "no parent"; it now returns none.

Returns

  • the parent path, or none for a root (/, C:\, a bare prefix such as C:), a bare name with no root (a, ., ..), or the empty path

Example

import io;

var p = io.Path("/a/b/c.txt").parent().value();   # "/a/b"
var root = io.Path("/a").parent().value();        # "/"
var none = io.Path("/").parent();                 # none

file_name

file_name(): String?

Returns the last component of the path, ignoring trailing separators (a/b/ gives b).

Breaking change: this used to return "" for "no file name"; it now returns none.

Returns

  • the last component, or none for a root (/, C:\), the empty path, or a path whose last component is . or ..

Example

import io;

var name = io.Path("/a/b/c.txt").file_name().value();   # "c.txt"
var none = io.Path("a/..").file_name();                 # none

file_stem

file_stem(): String?

Returns the file name without its extension: everything before the last dot, unless that dot is the first character.

Breaking change: this used to return "" for "no file name"; it now returns none.

Returns

  • the stem (c.tar for c.tar.gz, .bashrc for .bashrc, foo for foo., noext for noext), or none when there is no file name (see file_name())

extension

extension(): String?

Returns the file name's extension, without its dot: the text after the last dot, unless that dot is the first character. Only the file name counts; a dot in a directory name (a.b/c) is not an extension.

Breaking change: this used to return "" for "no extension"; it now returns none. As in Rust, a name ending in a dot (foo.) has the empty extension, which is not none.

Returns

  • the extension (gz for c.tar.gz, "" for foo.), or none when the file name has no dot after its first character (noext, .bashrc) or there is no file name

with_extension

with_extension(ext: String): Path

Returns this path with its file name's extension replaced by ext, added when it has none, or removed when ext is empty. Trailing separators after the file name are dropped.

Parameters

  • ext — the new extension without a leading dot (a dot is inserted; ".md" would give b..md), or "" to remove the extension

Returns

  • the new path, or a copy of this path unchanged when it has no file name (a root, ., .., or the empty path)

Example

import io;

var md = io.Path("a/b.txt").with_extension("md");   # "a/b.md"
var rs = io.Path("a/b").with_extension("rs");       # "a/b.rs"
var bare = io.Path("a/b.txt").with_extension("");   # "a/b"

components

components(): Array<String>

Returns the path split into its components: the prefix (Windows drive or UNC share, such as C:), then the root separator (one character, as written), then each non-empty part between separators.

Repeated and trailing separators produce no empty parts. . parts are dropped, except a leading one in a path with no prefix or root (./a gives . and a). .. parts are kept as they are.

Returns

  • the components in order; empty for the empty path

Example

import io;

var c = io.Path("/usr//lib/./x/").components();   # ["/", "usr", "lib", "x"]
var d = io.Path("./a/b").components();            # [".", "a", "b"]

normalize

normalize(): Path

Returns the path cleaned up lexically, without touching the file system: . parts and repeated or trailing separators are dropped, and each .. removes the part before it.

A .. cannot climb above a root (/../x gives /x) and is kept at the start of a relative path (../a/.. gives ..). The prefix is kept, and every separator becomes the platform separator. Because symlinks are not consulted, link/.. becomes . even when link points elsewhere; use canonicalize() for the path the file system resolves.

Returns

  • the normalized path; . when the path cleans to nothing (a/.., ./), and the empty path for the empty path

See also

  • canonicalize

Example

import io;

var p = io.Path("a/./b/../c").normalize();   # "a/c" ("a\c" on Windows)
var q = io.Path("a/..").normalize();         # "."

exists

exists(): bool

Returns whether something exists at this path, following symlinks. A relative path is resolved against the current directory.

Any error counts as not existing: a dangling symlink, a path under a directory that cannot be read, and the empty path all give false. Use metadata() to tell those apart.

Returns

  • true when the path (or a symlink's target) can be stat'ed

is_file

is_file(): bool

Returns whether the path names a regular file, following symlinks.

Returns

  • true for a regular file or a symlink to one; false for anything else, and on any error (including a missing path)

is_directory

is_directory(): bool

Returns whether the path names a directory, following symlinks.

Returns

  • true for a directory or a symlink to one; false for anything else, and on any error (including a missing path)

is_dir

[Deprecated("use 'is_directory' instead", "is_directory")] is_dir(): bool

Deprecated: use is_directory instead. Returns whether the path names a directory, following symlinks.

Returns

  • the same as is_directory()

metadata

metadata(): IoResult<Metadata>

Returns the metadata of the file or directory at this path, following symlinks: the result describes the target (so on POSIX is_symlink is always false). stat / statx on POSIX; on Windows the path is opened for attributes only.

Returns

  • the Metadata of the path (or of a symlink's target); an error when the path cannot be stat'ed: is_not_found() when it (or a symlink's target) is missing or the path is empty, is_permission_denied() when a directory on the way cannot be searched, and on POSIX is_not_a_directory() when a file is used as a directory in the middle of the path

See also

  • symlink_metadata

Example

import io;

var m = io.Path("data.bin").metadata();
if (m.is_ok()) {
    var size = m.value().size;
}

symlink_metadata

symlink_metadata(): IoResult<Metadata>

Returns the metadata of the path itself without following a symlink at the end of it, so for a symlink is_symlink is true and the rest describes the link rather than its target. lstat / statx with AT_SYMLINK_NOFOLLOW on POSIX; on Windows the path is opened with FILE_FLAG_OPEN_REPARSE_POINT, and any reparse point (junctions included) reports is_symlink, together with is_directory for a directory link. For anything that is not a symlink it equals metadata().

Returns

  • the Metadata of the path itself; an error as for metadata(), except that a dangling symlink succeeds

See also

  • metadata

canonicalize

canonicalize(): IoResult<Path>

Returns the absolute path the file system resolves this path to: relative to the current directory, with every symlink, . and .. resolved. Unlike normalize(), the path must exist.

POSIX uses realpath. Windows opens the path and asks for its final name; the result uses \, and the \\?\ prefix Windows reports is removed (\\?\UNC\server\share becomes \\server\share).

Returns

  • the canonical absolute path; an error when the path cannot be resolved: is_not_found() when it (or a symlink's target) is missing or the path is empty, is_permission_denied() when a directory on the way cannot be searched

See also

  • normalize

Example

import io;

var real = io.Path("a/../b.txt").canonicalize();
if (real.is_ok()) {
    print(real.value().to_string());
}

read_link

read_link(): IoResult<Path>

Returns the target a symbolic link points to, as stored in the link (readlink on POSIX; on Windows the reparse point's target, junctions included). Only the link itself is read: a relative target stays relative to the directory holding the link, and the target need not exist.

On Windows the \??\ prefix of an absolute target is removed (\??\UNC\server\share becomes \\server\share).

Returns

  • the link's target; an error with is_invalid_input() when the path is not a symlink, is_not_found() when it is missing or empty, or another platform error

See also

  • File.symlink
  • Directory.symlink

Example

import io;

var target = io.Path("current").read_link();
if (target.is_ok()) {
    print(target.value().to_string());
}

set_permissions

set_permissions(mode: Mode): IoResult<void>

Sets the permission bits of the file or directory at this path, following symlinks (chmod on POSIX).

mode holds the raw platform bits, as Metadata.permissions reports them: on POSIX the mode_t bits mode & 07777 (493, octal 755, for rwxr-xr-x). A directory's bits control listing it (r), creating and removing entries in it (w) and reaching anything inside it (x). On Windows mode is the FILE_ATTRIBUTE_* word, and only FILE_ATTRIBUTE_READONLY (1) is applied. WASI has no permission bits, and this fails. set_read_only and set_executable change one property portably.

Parameters

  • mode — the new permission bits

Returns

  • an Ok result once they are set; an error with is_not_found() when the path is missing or empty, is_permission_denied() when the caller does not own it, or another platform error

See also

  • File.set_permissions

Example

import io;

io.Path("deploy.sh").set_permissions(493);   # octal 755: rwxr-xr-x

set_read_only

set_read_only(read_only: bool): IoResult<void>

Makes the file or directory at this path read-only, or writable again, following symlinks: the portable part of set_permissions.

On POSIX, read-only clears every write bit (octal 222), and writable sets only the owner's (octal 200), so nothing becomes writable by group or others this way. On Windows it sets or clears FILE_ATTRIBUTE_READONLY, which Windows ignores on a directory. Fails on WASI, which has no permission bits.

Parameters

  • read_only — true to make it read-only, false to make it writable by its owner

Returns

  • an Ok result once it is changed; an error as for metadata() or set_permissions

See also

  • Metadata.read_only

Example

import io;

var config = io.Path("settings.toml");
config.set_read_only(true);
var ro = config.metadata().value().read_only;   # true

set_executable

set_executable(executable: bool): IoResult<void>

Makes the file at this path executable, or not, following symlinks, without raw permission bits.

On POSIX, executable adds an execute bit for each class (owner, group, others) that may read the file, as chmod +x does with the usual umask; not executable clears all three. Windows has no execute bit (an extension such as .exe decides) and WASI no permission bits, so there this does nothing and succeeds.

Parameters

  • executable — true to make the file executable, false to stop it

Returns

  • an Ok result once it is changed; an error as for metadata() or set_permissions

Example

import io;

io.File.write_text(io.Path("hello.sh"), "#!/bin/sh\necho hello\n");
io.Path("hello.sh").set_executable(true);

set_modified

set_modified(time: long): IoResult<void>

Sets the modification time of the file or directory at this path, following symlinks and leaving its access time alone (utimensat on POSIX, SetFileTime on Windows, where the time is kept to 100 ns).

A directory's modification time changes whenever an entry is added or removed, so set it after its contents are final.

Parameters

  • time — the new time, in nanoseconds since the Unix epoch, as Metadata.modified reports it

Returns

  • an Ok result once the time is set; an error with is_not_found() when the path is missing or empty, is_permission_denied() when the caller may not change it, or another platform error

See also

  • File.set_modified

Example

import io;

var source = io.Path("a.txt").metadata().value();
io.Path("b.txt").set_modified(source.modified);

set_accessed(time: long): IoResult<void>

Sets the access time of the file or directory at this path, following symlinks and leaving its modification time alone (utimensat on POSIX, SetFileTime on Windows, where the time is kept to 100 ns).

Parameters

  • time — the new time, in nanoseconds since the Unix epoch, as Metadata.accessed reports it

Returns

  • an Ok result once the time is set; an error as for set_modified

operator ==

==(rhs: Path): bool

Returns whether two paths have exactly the same text. The comparison is byte by byte, with no normalization and case-sensitive on every platform: a/b differs from a//b, from a/b/, and (on Windows) from a\b and A/b. Compare normalize() or canonicalize() results to ignore spelling differences.

Parameters

  • rhs — the path to compare with

Returns

  • true when both paths' texts are equal

operator !=

!=(rhs: Path): bool

Returns whether two paths differ in their text: the opposite of ==, with the same byte-by-byte comparison.

Parameters

  • rhs — the path to compare with

Returns

  • true when the paths' texts differ

hash

hash<Path>(value: Path): u64

Returns a hash of a path's text, so paths that are == hash equally and a Path keys a HashMap or HashSet by its text. O(length).

Parameters

  • value — the path to hash

Returns

  • the 64-bit hash of the path's text
