Deque

struct Deque<T>

A double-ended queue: a sequence that grows and shrinks at both ends in amortized O(1).

Elements live in a ring buffer that doubles when full (starting at 4 slots), so push_front, push_back, pop_front and pop_back are amortized O(1), and indexing is O(1) with index 0 at the front. Use it for first-in first-out queues, breadth-first search, sliding windows and undo history; an Array takes O(count) to remove its first element.

For a struct T the deque holds a counted reference to each element, as an Array does: pushing acquires it, and popping hands the deque's reference to the caller. Deque is itself a struct, so assigning it shares the same deque. A Deque is not [Shared]: keep each one on one thread.

A Deque is Iterable<T>: for (var x in d) visits the elements from front to back. Every change (a push, a pop, an element store, clear) invalidates running iterators, and the next step of such a loop panics with "Deque modified during iteration". An array converts to a deque, so an array literal can initialize one.

Type parameters

  • T — the element type

Example

Deque<int> queue = [1, 2];
queue.push_back(3);
queue.push_front(0);
assert(queue.pop_front() == 0, "front first");
assert(queue.pop_back() == 3, "then the back");
assert(queue[0] == 1 and queue.count == 2, "1 and 2 remain");

Deque()

Creates an empty deque with room for capacity elements before it grows.

Parameters

Deque()

[Implicit] construct(items: T[])

Creates a deque holding the elements of items, front to back in index order. The array is copied, not shared.

The constructor is [Implicit]: an array converts to a deque wherever a deque is expected, so an array literal can initialize one.

Parameters

  • items — the elements, the first at the front

Example

Deque<String> names = ["ada", "grace"];
assert(names.front() == "ada", "the first element is the front");

clear

clear()

Removes every element, releasing each one. The deque keeps its capacity. Invalidates running iterators.
