Comparable

trait Comparable

A type whose values have one order: compare says whether a value sorts before, with or after another.

Declaring it (extend Version with Comparable;) gives the type <, <=, > and >= and the methods min, max and clamp, each written in terms of compare, unless the type declares its own. A generic function asks for an order with T: Comparable.

compare returns a negative number when this value sorts before other, zero when the two sort together, and a positive number when it sorts after. The order must be total and consistent: two calls with the same values give the same answer, and a.compare(b) has the opposite sign of b.compare(a). Array.sort(), Map and Set rely on that.

float and double are Comparable with a total order: NaN sorts after every number and with every other NaN, and -0.0 with 0.0. Their < and > keep IEEE behavior (false whenever NaN takes part), while compare, clamp, Array.sort() and Map keys follow the total order.

Example

struct Version {
    var major: int;
    var minor: int;

    construct(this.major = 0, this.minor = 0) {}

    compare(other: Version): int {
        var order = major.compare(other.major);
        if (order != 0) {
            return order;
        }
        return minor.compare(other.minor);
    }
}

extend Version with Comparable;

assert(Version(1, 2) < Version(1, 10), "by minor");
assert(Version(2, 0).max(Version(1, 9)).major == 2, "max");

Parameters

  • other — the value to compare with

Returns

  • this value when it sorts after or with other, else other

Example

clamp

clamp(low: this, high: this): this

Returns this value limited to the range from low to high.

Parameters

  • low — the lowest value to return
  • high — the highest value to return

Returns

  • low when this value sorts before it, high when this value sorts after it, else this value

Panics

  • if low sorts after high ("clamp range is empty")

Example

assert((15).clamp(0, 10) == 10, "too high");
assert((-3).clamp(0, 10) == 0, "too low");
assert((4).clamp(0, 10) == 4, "in range");

extend float

extend float with Comparable

float values sort by value, with NaN after every number.

Methods

compare

compare(other: float): int

Returns the order of this value and other in a total order: by value, with NaN after every number and equal to every NaN, and -0.0 equal to 0.0.

Parameters

  • other — the value to compare with

Returns

  • -1, 0 or 1 as this value sorts before, with or after other

Example

var nan = (0.0 / 0.0) as float;
assert((1.0 as float).compare(nan) < 0, "NaN sorts last");
assert(nan.compare(nan) == 0, "NaNs sort together");

extend Array

extend Array<T: Comparable>

Arrays of Comparable elements sort in the elements' own order.

Methods

sort

sort()

Sorts the elements in place into their own order, compare: by value for numbers (NaN last), by content for String. The sort is stable and otherwise behaves like sort(compare).

Panics

  • if comparing modifies the Array ("Array modified during sort")

Example

var numbers = [3, 1, 2];
numbers.sort();   # [1, 2, 3]
