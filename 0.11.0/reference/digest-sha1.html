The Pepper Programming Language

SHA-1

SHA-1 (FIPS 180-4): 20-byte digests, as git uses for object ids. SHA-1 is broken for collision resistance; use it to read existing formats, and SHA-256 or BLAKE3 for anything new.

Source: runtime/digest/sha1.pep

Sha1

struct Sha1

An incremental SHA-1 hasher: feed it bytes with update, any number of times and in pieces of any size, then read the 20-byte digest with finish.

SHA-1 is not collision resistant: someone can make two inputs with the same digest. Use it only where a format requires it, such as git object ids. finish resets the hasher, so it can hash a new input.

Example

import digest;

# The id git gives an empty file ("blob 0" and a NUL byte).
u8[] nul = [0];
var hasher = digest.Sha1();
hasher.update("blob 0");
hasher.update(nul);
assert(hasher.finish_hex() == "e69de29bb2d1d6434b8b29ae775ad8c2e48c5391", "git blob id");
