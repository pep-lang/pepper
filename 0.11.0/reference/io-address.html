The Pepper Programming Language

Network addresses

Network addresses: IpAddress (IPv4 or IPv6), SocketAddress (an IP address and a port), and resolve, which turns a host name into socket addresses.

Source: runtime/io/address.pep

IpAddress

struct IpAddress

An IPv4 or IPv6 address.

Make one with IpAddress.v4, IpAddress.v6, IpAddress.parse, or one of the well-known addresses (loopback_v4(), unspecified_v6(), ...). IpAddress() is the IPv4 unspecified address 0.0.0.0.

to_string() prints IPv4 in dotted decimal (127.0.0.1) and IPv6 in the RFC 5952 form (::1, 2001:db8::8a2e:370:7334); an IPv4-mapped IPv6 address prints as ::ffff:1.2.3.4. An IPv4 address and the IPv6 address that maps it are different values.

An IPv6 address can carry a scope id, the network interface a link-local address such as fe80::1 belongs to. Its text form is fe80::1%eth0 (RFC 4007), and a socket address carries it to the system as sin6_scope_id.

See also

  • SocketAddress

Example

import io;

var a = io.IpAddress.parse("192.168.1.10").value();
var b = io.IpAddress.v6(8193, 3512, 0, 0, 0, 0, 0, 1);   # 2001:db8::1
print(a.is_v4());         # true
print(b.to_string());     # 2001:db8::1

parse

static parse(text: String): IoResult<IpAddress>

Parses an IPv4 address in dotted decimal (192.168.0.1) or an IPv6 address in the RFC 4291 text form (::1, fe80::1:2, ::ffff:10.0.0.1), with an optional scope (fe80::1%eth0).

IPv4 needs exactly four decimal parts from 0 to 255 without leading zeros. IPv6 takes up to eight groups of one to four hex digits (either case), at most one ::, and an optional IPv4 address as the last 32 bits. Brackets and surrounding spaces are not accepted.

An IPv6 address may end in % and a scope: a decimal scope id (%3), or the name of a network interface (%eth0), which is looked up on this machine (so it fails where there is no such interface).

Parameters

  • text — the address to parse

Returns

  • the address; an error with is_invalid_input() when text is not a valid IPv4 or IPv6 address or names an unknown interface

Example

var r = IpAddress.parse("10.0.0.300");
print(r.is_err());   # true: 300 is out of range
var scoped = IpAddress.parse("fe80::1%7").value();
print(scoped.scope_id());   # 7

to_string

to_string(): String

Returns the address as text: dotted decimal for IPv4, the RFC 5952 form for IPv6 (lowercase hex, leading zeros dropped, the longest run of two or more zero groups written ::, ::ffff:a.b.c.d for an IPv4-mapped address). A scope id follows as % and the name of its interface (fe80::1%eth0), or the number when no interface on this machine has that index (fe80::1%9).

Returns

  • the text form, which IpAddress.parse reads back

operator ==

==(other: IpAddress): bool

Returns whether two addresses are the same: same family, same bytes and same scope id. An IPv4 address never equals an IPv6 one, not even the IPv6 address that maps it.

Parameters

  • other — the address to compare with

Returns

  • true when both are equal

operator !=

!=(other: IpAddress): bool

Returns whether two addresses differ.

Parameters

  • other — the address to compare with

Returns

  • true when the family, any byte or the scope id differs

SocketAddress

struct SocketAddress

An IP address and a port: where a socket is bound, or where it connects or sends.

Make one with SocketAddress(address, port) or SocketAddress.parse, or get a list from resolve. SocketAddress() is 0.0.0.0:0. The text form is address:port for IPv4 and [address]:port for IPv6.

See also

  • IpAddress
  • resolve

Example

import io;

var any = io.SocketAddress(io.IpAddress.unspecified_v4(), 8080);
var local = io.SocketAddress.parse("[::1]:443").value();
print(local.port());   # 443

resolve

resolve(host: String, port: u16): IoResult<SocketAddress[]>

Looks up the socket addresses of a host, with port attached to each.

A host that is already an IP address (as IpAddress.parse reads it) is returned as is, without a lookup. Anything else goes to the system resolver (getaddrinfo on POSIX, GetAddrInfoW on Windows), which consults the hosts file and DNS and blocks until it answers. The addresses come in the resolver's order of preference, IPv4 and IPv6 mixed, each at most once.

Parameters

  • host — a host name such as "example.com" or "localhost", or an IP address
  • port — the port to put in every result

Returns

  • at least one address; an error with is_not_found() when the name has no address, is_invalid_input() when host is empty, or another resolver error

Example

import io;

var r = io.resolve("localhost", 8080);
if (r.is_ok()) {
    for (var address in r.value()) {
        print(address.to_string());   # 127.0.0.1:8080, [::1]:8080, ...
    }
}
