BitSet

struct BitSet

A growable set of non-negative integers, one bit per possible member.

Member n is bit n % 64 of word n / 64, so a set whose largest member is m takes about m / 8 bytes whatever its count: a good fit for visited flags, masks, and sieve or liveness tables over small integers. For sparse or large integers use a HashSet<int>.

insert grows the set as needed and reserve grows it ahead of time; the set never shrinks. contains and remove take O(1); count, is_empty, ==, hash, iteration and the set operations take O(capacity / 64).

Two sets are == when they hold the same members, whatever their capacity, and equal sets hash equally, so a BitSet works as a HashMap or HashSet key. A BitSet is not [Shared]: keep each one on one thread.

Example

BitSet primes = [2, 3, 5, 7];
primes.insert(11);
assert(primes.contains(5), "a member");
assert(primes.count == 5, "five members");
for (var p in primes) {
    print($"{p}");   # 2, 3, 5, 7, 11
}

Properties

Constructors

BitSet()

construct(capacity: int = 0)

Creates an empty set with room for the members 0 up to (not including) capacity before it grows.

Parameters

  • capacity — the number of members to make room for; rounded up to a multiple of 64

Panics

  • if capacity is negative

BitSet()

[Implicit] construct(items: int[])

Creates a set holding each element of items.

The constructor is [Implicit]: an array converts to a set wherever a set is expected, so an array literal can initialize one.

Parameters

  • items — the members to insert; duplicates are kept once

Panics

  • if an element of items is negative

Example

BitSet flags = [1, 4, 4];
assert(flags.count == 2, "4 is kept once");

remove

remove(n: int): bool

Removes n from the set. Does nothing when n is not a member.

Parameters

  • n — the integer to remove

Returns

  • true when n was a member and was removed, false otherwise

iterate

iterate(): BitSetIterator

Returns an iterator over the members in ascending order; for (var n in set) drives it.

The iterator holds a reference to the set. Changing the set while iterating is safe: the iterator sees the members above its position as they are when it reaches them.

Returns

  • an iterator positioned before the smallest member

hash

hash<BitSet>(value: BitSet): u64

Returns a hash of the members of value, so equal sets hash equally whatever their capacity and a BitSet works as a HashMap or HashSet key. O(capacity / 64).

Parameters

Returns
