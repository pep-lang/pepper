The Pepper Programming Language

JsonValue

JsonValue: a JSON value of any kind, and how it is written as text.

Source: runtime/json/value.pep

JsonValue

enum JsonValue

A JSON value: null, a boolean, a number, a string, an array or an object. json.parse makes one from text and to_string writes it back.

Look values up with value["key"] and value[index]. A lookup that finds nothing (a missing key, an index past the end, or a lookup on a value of another kind) gives Null rather than panicking, so lookups chain: root["server"]["port"]. Then read the value with an as_ method, which gives none when the value is of another kind, or match on its case.

Numbers keep the form they were written in: an integer within ±(2^53 − 1), the range every JSON implementation agrees on (RFC 7493), is an Integer; any other number is a Number, a double.

An Array or Object case holds its array or map by reference, so changing them through value[key] = ..., append or the map from as_object() changes every holder of the value.

Example

import json;

var reply = json.JsonValue.object();
reply["id"] = json.JsonValue.Integer(42);
reply["tags"] = json.JsonValue.array([json.JsonValue.String("a")]);
assert(reply.to_string() == "{\"id\":42,\"tags\":[\"a\"]}", "compact");
assert(reply["id"].as_int().value() == 42, "a lookup");
assert(reply["missing"]["deeper"].is_null(), "lookups chain");

import json;

array

static array(items: Array<JsonValue> = Array<JsonValue>()): JsonValue

Returns an array holding items, which it keeps by reference rather than copying.

Parameters

  • items — the elements; an empty array when not given

Returns

  • an Array of items

Example

import json;

var list = json.JsonValue.array([json.JsonValue.Integer(1)]);
list.append(json.JsonValue.Integer(2));
assert(list.to_string() == "[1,2]", "two elements");

as_int

as_int(): long?

Returns the number as an integer, when it is one: an Integer, or a Number with no fraction that fits in a long (2.0, 1e3).

Returns

  • the integer, or none

Example

import json;

assert(json.parse("1e3").value().as_int().value() == 1000, "no fraction");
assert(json.parse("1.5").value().as_int().is_empty(), "a fraction");

to_string

to_string(): String

Returns the value as compact JSON text, with no spaces or line breaks: {"id":42,"tags":["a","b"]}.

Strings are written as UTF-8, escaping ", \ and the control characters. A Number that is not finite (NaN or an infinity, which JSON cannot spell) is written as null.

Returns

  • the JSON text

to_string

to_string(ascii_only: bool): String

Returns the value as compact JSON text, like to_string(), choosing whether to escape every character outside ASCII as \u (a pair of them past U+FFFF), so the text is plain ASCII.

Parameters

  • ascii_only — whether to escape every non-ASCII character

Returns

  • the JSON text

Example

import json;

var word = json.JsonValue.String("é");
assert(word.to_string(ascii_only = true) == "\"\\u00e9\"", "escaped");

to_pretty_string

to_pretty_string(indent: int = 2, ascii_only: bool = false): String

Returns the value as indented JSON text: each element and member on its own line, indented indent spaces per level, with a space after each :. An empty array or object stays [] or {}.

Parameters

  • indent — the number of spaces per level of nesting
  • ascii_only — whether to escape every non-ASCII character as \u

Returns

  • the JSON text, without a final line break

Panics

  • if indent is negative ("JsonValue.to_pretty_string needs a non-negative indent")

Example

import json;

var list = json.JsonValue.array([json.JsonValue.Integer(1)]);
assert(list.to_pretty_string() == "[\n  1\n]", "two spaces");
