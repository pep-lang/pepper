The Pepper Programming Language

Formats and streams

Format, the one-call Deflate, Zlib and Gzip functions, and the streaming DecompressReader and CompressWriter.

Source: runtime/compress/format.pep

Format

enum Format

The framing around DEFLATE-compressed data.

Example

import compress;

var packed = compress.Gzip.compress("hi".bytes());
var reader = compress.DecompressReader(io.ByteReader(packed), compress.Format.Gzip);

Cases

Raw

Raw

Raw DEFLATE (RFC 1951) with no header or checksum, as zip archives and HTTP's Content-Encoding: deflate from some servers carry it.

Zlib

Zlib

zlib (RFC 1950): a two-byte header, DEFLATE, then an Adler-32 checksum. PNG images and HTTP's deflate encoding use it.

Gzip

Gzip

gzip (RFC 1952): a header, DEFLATE, then a CRC-32 and the length. .gz files and HTTP's gzip encoding use it. Reading accepts several members one after another, as cat a.gz b.gz makes.

Deflate

struct Deflate

Raw DEFLATE (RFC 1951) data, compressed or decompressed in one call.

Example

import compress;

var data = "abcabcabcabc".bytes();
var packed = compress.Deflate.compress(data);
assert(compress.Deflate.decompress(packed).value() == data, "round trip");

Zlib

struct Zlib

zlib (RFC 1950) data, compressed or decompressed in one call.

Example

import compress;

var packed = compress.Zlib.compress("hello".bytes());
assert(packed[0] == 0x78, "the zlib header");
assert(compress.Zlib.decompress(packed).value() == "hello".bytes(), "round trip");

compress

static compress(data: u8[], dictionary: u8[], level: int = 6): u8[]

Compresses data into a zlib stream that starts from a preset dictionary: bytes the data is likely to repeat, such as the common keys of small JSON messages, which the stream can then refer back to without carrying them. The header names the dictionary by its Adler-32, and decompressing needs the same dictionary. Only its last 32 KiB are used.

Parameters

  • data — the bytes to compress
  • dictionary — the preset dictionary
  • level — from 0 (store without compressing) through 9 (smallest output, slowest); 6 balances the two

Returns

  • the compressed bytes

Panics

  • if level is not 0 through 9 ("compression level must be 0 through 9")

Example

import compress;

var dictionary = "{\"name\": \"\", \"email\": \"\"}".bytes();
var data = "{\"name\": \"Ada\", \"email\": \"ada@example.com\"}".bytes();
var packed = compress.Zlib.compress(data, dictionary);
assert(compress.Zlib.decompress(packed, dictionary).value() == data, "round trip");

decompress

static decompress(data: u8[]): io.IoResult<u8[]>

Decompresses a zlib stream and checks its Adler-32 checksum. Bytes after the stream are ignored. A stream made with a preset dictionary needs the overload that takes one.

Parameters

  • data — the compressed bytes

Returns

  • the decompressed bytes; an is_invalid_input() error when data is not a valid zlib stream, ends too soon, fails its checksum, or needs a preset dictionary

decompress

static decompress(data: u8[], dictionary: u8[]): io.IoResult<u8[]>

Decompresses a zlib stream that may need a preset dictionary, and checks its Adler-32 checksum. A stream that does not ask for a dictionary decompresses as without one.

Parameters

  • data — the compressed bytes
  • dictionary — the preset dictionary the stream was compressed with

Returns

  • the decompressed bytes; an is_invalid_input() error when data is not a valid zlib stream, ends too soon, fails its checksum, or names a dictionary whose Adler-32 is not that of dictionary

Gzip

struct Gzip

gzip (RFC 1952) data, as in .gz files, compressed or decompressed in one call.

Example

import compress;
import io;

var packed = compress.Gzip.compress("hello".bytes());
io.File.write_bytes(io.Path("hello.txt.gz"), packed);
assert(compress.Gzip.decompress(packed).value() == "hello".bytes(), "round trip");

DecompressReader

struct DecompressReader

A Reader that decompresses another stream as it is read, such as a .gz file or an HTTP response body, without holding all of it in memory.

It reads its source in chunks of up to 64 KiB and keeps at most about 160 KiB of output, however large the data. Corrupt or truncated data is an is_invalid_input() error from read, after the bytes decoded before the problem; an error from the source is passed on.

Example

import compress;
import io;

var file = io.File.open(io.Path("notes.txt.gz")).value();
var reader = compress.DecompressReader(file, compress.Format.Gzip);
for (var line in reader.lines()) {
    print(line.value());
}

CompressWriter

struct CompressWriter

A Writer that compresses what is written to it and writes the result to another stream, such as a .gz file.

Compressed bytes reach the sink in pieces as blocks fill; finish() writes the rest and the format's trailer, and must be called once at the end, since dropping the writer does not. It does not close the sink.

Example

import compress;
import io;

var file = io.File.create(io.Path("log.txt.gz")).value();
var writer = compress.CompressWriter(file, compress.Format.Gzip);
writer.print_line("first line");
writer.print_line("second line");
writer.finish();
file.close();

Parameters
