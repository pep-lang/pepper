The Pepper Programming Language

Streams in memory

ByteReader and ByteWriter: a Reader over bytes already in memory, and a Writer that collects what is written into memory, for code that takes a stream when the data is in an array.

Source: runtime/io/memory.pep

ByteReader

struct ByteReader

A Reader over an array of bytes: each read takes the next bytes of the array, and the stream ends after its last byte.

The reader keeps a reference to the array and does not copy it; changing the array while reading changes what is read.

Example

import io;

var data = "one\ntwo\n".bytes();
var count = 0;
for (var line in io.ByteReader(data).lines()) {
    count += 1;
}
assert(count == 2, "two lines");

ByteWriter

struct ByteWriter

A Writer that appends everything written to an array in memory, bytes.

Example

import io;

var out = io.ByteWriter();
out.print("n = ");
out.print_line(3);
assert(out.bytes == "n = 3\n".bytes(), "collected");
